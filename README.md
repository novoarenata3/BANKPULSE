# BANKPULSE - Plataforma de Pagos Digitales

## Descripción
BANKPULSE es un esqueleto ejecutable de aplicación de pagos y transferencias en tiempo real diseñado bajo la arquitectura MVC para la materia de Diseño de Sistemas (USFQ).

## Requisitos
- Docker Desktop / Docker Engine (versión 20.10 o superior)
- Git
